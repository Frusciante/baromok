# Phase 5 변경 요약: 파트너 공유용

**작성일**: 2026-05-09  
**대상**: Phase 5 Step 1~4 반영 내용 요약  
**목적**: 최근 코드 변경 사항을 추가/제거/개선/수정 관점에서 빠르게 공유하기 위한 문서

---

## 한눈에 보는 변경 결과

Phase 5에서는 설정값이 실제 동작에 반영되도록 연결했고, 알림음과 자동 감지 시작을 추가했으며, 통합 흐름 검증까지 마쳤습니다.

핵심적으로는 다음 4가지가 완료되었습니다.

- 설정 화면의 값이 앱 동작에 즉시 적용됨
- 경고 발생 시 알림음 재생 기능 추가
- Baseline 완료 후 자동 감지 시작 기능 추가
- 감지 시작/중지/경고/설정 저장 흐름의 통합 검증 완료

추가로, `app.py`와 `src/ui/screens/__init__.py` 쪽에서도 화면 흐름과 알림 처리 방식이 함께 손봐졌습니다.

- Baseline 화면의 종료 기준이 5초 고정에서 유효 프레임 기반으로 변경됨
- Baseline 완료 후 Hub 이동 또는 자동 감지 시작으로 분기됨
- 경고 알림음이 UI 스레드를 막지 않도록 백그라운드 재생으로 처리됨

그리고 `src/core` 폴더 내부도 실제 판정/수집/추출 기준이 함께 정리되었습니다.

- `baseline_manager.py`: Baseline 저장 기준을 더 엄격하게 검증하도록 변경
- `camera_worker.py`: Baseline 모드와 일반 감지 모드를 분리
- `judgment_engine.py`: 자세 확정 조건과 지속 시간 추적을 정교화
- `landmark_extractor.py`: 얼굴 랜드마크 추출과 좌우 판별 기준을 정리
- `sound_manager.py`: 경고음 재생 책임을 별도 모듈로 분리

## 추가된 기능

### 1. 알림음 기능 추가
- 경고 발생 시 Windows 기본 음성 알림이 재생됩니다.
- 음량 설정값을 반영합니다.
- 알림음 관리 책임을 `SoundManager`로 분리했습니다.

### 2. 자동 감지 시작 기능 추가
- Baseline 촬영이 끝나면 설정값에 따라 자동으로 감지를 시작할 수 있습니다.
- 자동 시작이 꺼져 있으면 기존처럼 Hub 화면으로 이동합니다.

### 3. Baseline 화면 동작 개선
- `src/ui/screens/__init__.py`의 BaselineScreen이 5초 고정 종료가 아니라 유효 프레임 수를 기준으로 종료됩니다.
- 초기 안정화 프레임을 제외한 뒤, 실제 수집 품질이 충분할 때만 Baseline 저장을 완료합니다.
- 촬영 실패 시에도 카메라 정리와 상태 초기화가 일관되게 처리됩니다.

### 4. core 수집 기준 개선
- `src/core/baseline_manager.py`가 유효 프레임 수가 부족하면 저장을 중단합니다.
- Baseline 저장 전에 실제 수집 품질이 기준을 만족하는지 확인합니다.
- 잘못된 또는 빈 프레임은 수집 단계에서 제외합니다.

### 5. 설정값 실시간 적용
- 알림 간격
- 팝업 위치
- 팝업 자동 닫기 시간
- 알림음 사용 여부 및 음량

위 항목들이 저장 직후 다음 동작부터 반영됩니다.

---

## 없어진 기능 또는 제거된 고정 동작

이번 변경에서 사용자 기능이 사라진 것은 없습니다. 대신 아래와 같은 고정 동작을 제거했습니다.

- 경고 쿨다운 3초 고정값 제거
- 팝업 중앙 고정 위치 제거
- 팝업 자동 닫기 3초 고정값 제거
- Baseline 완료 후 항상 수동 시작으로만 이어지던 단일 흐름 제거

즉, 기능 삭제가 아니라 고정값 중심 동작을 설정 기반 동작으로 바꾼 것입니다.

---

## 개선된 기능

### 1. 팝업 동작 개선
- 팝업 위치를 중앙 또는 상단으로 선택 가능
- 팝업 자동 닫기 시간을 설정값으로 제어
- 자동 닫기를 끌 수도 있어 수동 확인 흐름 지원

### 2. 알림 처리 방식 개선
- 알림음 재생을 백그라운드 스레드로 분리해 UI 응답성을 유지
- 연속 경고 상황에서 중복 재생을 줄이도록 쿨다운을 적용

### 3. 설정 반영 방식 개선
- 저장된 값을 다시 읽는 것이 아니라 실행 중에도 바로 반영되도록 변경
- 설정 변경 후 재시작 부담을 줄임

### 4. 코드 구조 개선
- 알림음 처리 로직을 별도 관리자 클래스로 분리
- 앱 본문에서는 경고 표시와 설정 연동에 집중하도록 정리

---

## 수정된 기능

### 1. 설정 미적용 문제 수정
- 기존에는 저장된 설정이 실제 동작에 완전히 반영되지 않는 문제가 있었습니다.`
- 이제 알림 간격, 팝업 위치, 자동 닫기 시간이 실제 동작에 반영됩니다.

### 2. 알림음 미구현 문제 수정
- 설정에는 있었지만 실제 재생 로직이 없던 문제를 해결했습니다.

### 3. 팝업 위치 고정 문제 수정
- 경고 팝업이 항상 같은 위치에 뜨던 문제를 해결했습니다.

### 4. 자동 감지 시작 연결 수정
- Baseline 완료 후 설정값에 따라 자동 시작 또는 수동 이동으로 분기되도록 수정했습니다.

### 5. Baseline 종료 기준 수정
- `src/ui/screens/__init__.py`의 BaselineScreen이 고정 시간 종료 대신 실제 유효 프레임 기준으로 완료됩니다.
- 촬영 품질이 부족하면 저장하지 않고 다시 촬영하도록 유도합니다.

### 6. core 판정/추출 로직 수정
- `src/core/camera_worker.py`가 Baseline 수집 중에는 일반 판정과 상태 전이를 건너뛰도록 수정되었습니다.
- `src/core/judgment_engine.py`는 triggered된 자세만 우선 판정하고, 자세 지속 시간을 별도로 추적하도록 정리되었습니다.
- `src/core/landmark_extractor.py`는 얼굴 랜드마크를 더 안정적인 기준점으로 추출하고 좌우를 x좌표 기준으로 정리합니다.

### 7. 통합 흐름 검증 완료
- Baseline 완료, 감지 시작, 경고 팝업, 감지 중지, 설정 저장/로드 흐름을 모두 확인했습니다.
