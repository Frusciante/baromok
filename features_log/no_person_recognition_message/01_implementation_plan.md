# 구현 계획: 사용자 미탐지 시 '인식이 어렵습니다' 문구 표시

**작성일**: 2026-05-13  
**대상**: 초기 자세 감지 / 메인 감지 공통

---

## 목표

카메라 프레임에서 사용자의 모습이 충분히 탐지되지 않을 때 `인식이 어렵습니다` 문구를 표시한다. 이 문구는 초기 자세 촬영 화면과 메인 감지 화면에서 모두 동일하게 동작해야 한다.

---

## 범위

### 포함
- 카메라 워커가 프레임 단위로 사용자 미탐지 여부를 함께 전달
- 초기 자세 촬영 화면에서 미탐지 시 안내 문구 표시
- 메인 감지 화면에서 미탐지 시 안내 문구 표시
- 관련 UI/동작 체크리스트 문서 갱신

### 제외
- 경고 팝업 문구 변경
- 자세 판정 임계값 변경
- 세션 통계 로직 변경

---

## 구현 방향

1. `CameraWorker.process_frame()`에서 사람/랜드마크 감지 여부를 판별한다.
2. 프레임 데이터에 미탐지 상태를 담아 화면으로 전달한다.
3. `BaselineScreen`과 `DetectionScreen`은 해당 상태를 읽어 동일한 문구를 보여준다.
4. 감지가 다시 정상으로 돌아오면 문구를 숨긴다.

---

## 검증 계획

- 초기 자세 촬영 중 카메라 앞에 사람이 없을 때 문구가 보이는지 확인
- 메인 감지 중 카메라 앞에 사람이 없을 때 문구가 보이는지 확인
- 사람이 다시 잡히면 문구가 사라지는지 확인
- 앱 실행 시 기존 감지 흐름이 깨지지 않는지 확인
