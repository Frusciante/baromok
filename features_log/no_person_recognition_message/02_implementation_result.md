# 구현 결과: 사용자 미탐지 시 '인식이 어렵습니다' 문구 표시

**작성일**: 2026-05-13  
**대상**: 초기 자세 감지 / 메인 감지 공통

---

## 구현 완료 내용

### ✅ 초기 자세 촬영 화면 반영
- `indicators`가 없는 프레임이 들어오면 `인식이 어렵습니다` 문구를 표시한다.
- 유효 지표가 다시 들어오면 안내 문구를 숨긴다.
- 워밍업 구간에서도 미탐지 프레임이면 같은 문구가 유지되도록 경계 처리를 보강했다.

### ✅ 메인 감지 화면 반영
- `indicators`가 없는 프레임이 들어오면 `인식이 어렵습니다` 문구를 표시한다.
- 미탐지 상태에서는 자세 상태 라벨도 동일 문구로 덮어써서 오해를 줄인다.
- 유효 지표가 다시 들어오면 안내 문구를 숨기고 기존 자세 표시 흐름으로 복귀한다.

### ✅ UI 공통 헬퍼 정리
- `인식이 어렵습니다` 문구를 공유 상수로 분리했다.
- 라벨 표시/숨김을 공통 헬퍼로 묶어 두 화면의 동작을 일치시켰다.

### ✅ 문서 갱신
- UI 구현 상황 체크리스트 갱신
- 동작 구현 상황 체크리스트 갱신

## 확인한 동작

- 초기 자세 촬영에서 미탐지 시 문구 노출
- 메인 감지에서 미탐지 시 문구 노출
- 유효 지표 복귀 시 문구 숨김
- 기존 감지 흐름과 공존

- 이 방식으로 초기 자세 촬영과 메인 감지의 문구 정책을 한 번에 맞췄다.
