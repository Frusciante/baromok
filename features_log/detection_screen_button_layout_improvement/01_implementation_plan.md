# 탐지 화면 버튼 레이아웃 개선

## 1. 개요
탐지 화면 하단의 공간을 더 효율적으로 활용하기 위해, 기존에 작게 배치되었던 '재측정', '일시정지', '종료' 버튼의 레이아웃을 개선한다. 하단 공간을 3등분하여 버튼들이 충분한 공간을 차지하도록 하여 시인성과 클릭 편의성을 높인다.

## 2. 주요 변경 사항

### 2.1. 버튼 크기 정책 수정
- 기존: `setFixedSize`를 사용하여 가로 100px, 세로 42px로 고정.
- 변경: `setSizePolicy(QSizePolicy.Policy.Expanding, QSizePolicy.Policy.Fixed)`를 적용하여 가로 방향으로 가용한 공간을 가득 채우도록 수정. 세로 높이는 최소 46px로 소폭 확대.

### 2.2. 레이아웃 배치 수정
- 버튼들을 감싸는 `QHBoxLayout`의 `addStretch()`를 제거하고, 버튼들이 직접 레이아웃의 공간을 균등하게 나눠 갖도록 함.
- 버튼 간 간격(`setSpacing`)을 12px로 설정하여 조밀하지 않으면서도 일체감 있는 배치를 구현.
- 폰트 크기를 14에서 15로 상향하여 큰 버튼에 어울리는 시각적 균형을 맞춤.

## 3. 검증 계획
- [ ] 탐지 화면 진입 시 하단 버튼 3개가 좌우 끝까지 균등하게 배치되는지 확인.
- [ ] 창 크기 조절 시 버튼들이 가로 길이에 맞춰 유동적으로 늘어나는지 확인.
- [ ] 각 버튼의 기능(재측정, 일시정지, 종료)이 정상적으로 동작하는지 확인.
