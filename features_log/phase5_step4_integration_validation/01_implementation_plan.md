**예상 기간**: 2-3시간

## 목표

Phase 5-1, 5-2, 5-3에서 적용한 설정값 연동이 실제 앱 흐름 전체에서 충돌 없이 동작하는지 확인한다.

---

## 검증 범위

### 포함 항목
- Baseline 완료 후 자동 감지 시작 여부
- 감지 시작/중지 흐름
- 경고 팝업 표시 및 알림음 재생
- 설정 저장/로드 및 즉시 반영
- 세션 시작/종료 흐름

### 제외 항목
- 카메라 실영상 품질 평가
- 장시간 성능 측정
- UI 디자인 재작업

---

## 통합 검증 시나리오

### 1. Baseline 완료 후 흐름
- `auto_start_detection=False`일 때 Hub로 이동
- `auto_start_detection=True`일 때 자동으로 감지 시작

### 2. 감지 시작/중지 흐름
- `_start_detection()` 호출 시 상태 초기화
- 세션 시작
- 카메라 워커 시작
- `_stop_detection()` 호출 시 세션 종료 및 화면 복귀

### 3. 경고 표시 흐름
- 상태 전이에 따라 팝업 표시
- `sound_enabled=True`일 때 알림음 재생
- `popup_auto_close` 설정에 따라 타이머 적용
- `popup_position` 설정에 따라 좌표 변경

### 4. 설정 저장/로드 흐름
- SettingsScreen에서 변경한 값이 저장되는지 확인
- JSON 저장 후 다시 로드했을 때 값이 유지되는지 확인

---

## 검증 방법

### 자동화 방식
- `baromokApp` 인스턴스 생성
- 주요 메서드와 컴포넌트를 더미 함수로 치환
- 상태 변화를 기록하여 기대값과 비교

### 확인할 항목
- 화면 전환 대상
- `start_session` / `end_session` 호출 여부
- `camera_worker.start` / `stop_capture` 호출 여부
- `sound_manager.play_alert` 호출 여부
- 팝업 타이머 활성화 여부
- 설정 JSON 저장/로드 일치 여부
