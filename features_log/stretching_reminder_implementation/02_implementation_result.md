# 스트레칭 권장 알림 기능 구현 결과

## 1. 구현 요약
장시간(기본 30분) 감지 세션이 유지될 경우 사용자에게 스트레칭을 권장하는 알림 기능을 성공적으로 구현했습니다. 이 기능은 일시정지 시간을 제외한 순수 활성 시간을 기준으로 작동합니다.

## 2. 주요 변경 사항

### 2.1. 설정 시스템 확장 (`src/config.py`)
- `SettingsConfig`에 `stretching_reminder_enabled` 및 `stretching_reminder_interval` 필드 추가.
- 기본값: 활성화(True), 간격 30분.

### 2.2. UI 설정 위젯 추가 (`src/ui/widgets/settings_widgets.py`, `src/ui/screens/settings_screen.py`)
- `StretchingSettingsWidget` 신규 구현: 토글 스위치와 10~120분 범위의 슬라이더 제공.
- 환경설정 화면의 그리드 레이아웃을 조정하여 '스트레칭 알림' 카테고리 배치.

### 2.3. 실시간 모니터링 로직 (`src/ui/app.py`)
- **1분 주기 타이머**: `_stretching_timer`를 통해 매분 현재 세션의 순수 활성 시간을 체크.
- **활성 시간 기준**: `CameraWorker.get_elapsed_time()`을 사용하여 일시정지 중에는 알림 카운트가 올라가지 않도록 처리.
- **중복 방지**: `_last_stretching_alert_minute` 변수를 사용하여 동일한 분에 여러 번 알림이 뜨는 것을 방지.
- **통합 알림**: 기존 알림 시스템(info 타입)을 활용하여 시각적 일관성 유지 및 알림음 재생.

## 3. 사용 방법
1. **환경설정** 메뉴로 이동합니다.
2. **스트레칭 알림** 카테고리에서 기능을 켜거나 끕니다.
3. 원하는 알림 간격(예: 45분)을 설정합니다.
4. 자세 감지를 시작하면, 설정된 시간마다 "XX분간 열중하셨네요! 잠시 어깨를 펴고 스트레칭 시간을 가져보세요." 팝업이 나타납니다.

## 4. 향후 개선 사항
- 스트레칭 가이드 이미지 또는 간단한 애니메이션을 팝업에 포함하여 효과 증대.
- 하루 중 총 스트레칭 횟수를 통계 화면에 추가.
