# 스트레칭 권장 알림 기능 구현 계획

## 1. 개요
장시간 한 자세로 작업하는 사용자에게 일정 시간(기본 30분)마다 스트레칭을 권장하는 알림을 제공하여 거북목 방지 및 건강한 습관 형성을 돕습니다.

## 2. 주요 기능
- **활성 시간 모니터링**: 일시정지를 제외한 순수 탐지 시간이 설정된 간격에 도달하면 알림 발생.
- **사용자 설정**:
    - 기능 On/Off 토글
    - 알림 간격 조절 (10분 ~ 120분 단위, 기본 30분)
- **알림 형태**: 기존 나쁜 자세 알림 팝업과 통일된 디자인의 안내 팝업 (내용: "30분간 열중하셨네요! 잠시 어깨를 펴고 스트레칭 시간을 가져보세요.")

## 3. 구현 세부 계획

### 3.1. 설정 관리 (`src/config.py`)
- `SettingsConfig` 데이터 클래스에 신규 필드 추가:
    - `stretching_reminder_enabled: bool` (기본값: True)
    - `stretching_reminder_interval: int` (단위: 분, 기본값: 30)

### 3.2. 모니터링 로직 (`src/ui/app.py`)
- `CameraWorker`에서 제공하는 `get_elapsed_time()`을 활용하여 실시간 체크.
- `QTimer`를 통해 1분마다 현재 세션의 활성 시간을 확인.
- 설정된 `stretching_reminder_interval`의 배수 시점에 도달할 때마다 알림 브리지를 통해 팝업 요청.
- **중복 방지**: 한 번 알림이 뜬 시점(분 단위)을 기록하여 동일 시간대에 여러 번 뜨지 않도록 처리.

### 3.3. UI 설정 추가 (`src/ui/widgets/settings_widgets.py`)
- `StretchingSettingsWidget` 신규 생성.
- 토글 스위치와 시간 조절 슬라이더(10~120분) 배치.
- '환경설정' 화면에 해당 카테고리 추가.

### 3.4. 알림 메시지 정의 (`.github/rules/operation/posture_definition_criteria.json`)
- 포괄적인 관리를 위해 JSON에 스트레칭 알림 문구 추가 고려 (또는 `app.py`에서 직접 관리).

## 4. 테스트 계획
- 설정 화면에서 토글 및 슬라이더가 정상 작동하는지 확인.
- 짧은 시간(예: 1분)으로 설정 후 실제 활성 시간이 경과했을 때 팝업이 나타나는지 확인.
- 일시정지 중에는 시간이 누적되지 않아 알림이 지연되는지 확인.
