# 바른 자세 가이드 UI 추가 및 탐지 로직 개선 결과 보고서

## 1. 개요
사용자가 올바른 기준 자세를 쉽게 파악하고 유지할 수 있도록 '바른 자세 가이드' 콘텐츠(이미지 및 지침)를 UI 전반에 추가하였습니다. 또한, 설정 변경 시 의도치 않게 탐지가 시작되는 문제를 해결하고 내비게이션 안정성을 높였습니다.

## 2. 주요 구현 내용

### A. 바른 자세 가이드 시스템 도입
- **재사용 위젯 구현 (`CorrectPostureGuideWidget`)**: `assets/ui/correct_posture.png` 이미지와 4대 핵심 지침을 결합한 가이드 컴포넌트 제작.
- **초기 자세 설정 (`BaselineScreen`) 개선**: '기준 자세 설정 가이드' 영역에 '바른 자세란?' 도움말 버튼 추가. 클릭 시 모달 팝업으로 상세 가이드 노출.
- **탐지 화면 (`DetectionScreen`) 레이아웃 개편**: 중앙 영역을 좌우로 분할하여, 좌측에는 실시간 프리뷰를, 우측에는 상시 확인 가능한 바른 자세 가이드 패널을 배치.

### B. 내비게이션 및 세션 관리 최적화
- **히스토리 스택 도입 (`src/ui/app.py`)**: 화면 이동 이력을 스택으로 관리하여, 설정 화면 종료 시 이전 화면(허브 또는 탐지 화면)으로 정확히 복귀하도록 개선.
- **탐지 게이팅 로직 강화**: `is_detecting` 플래그를 도입하여 카메라 예열 중에는 판정 로직 및 세션 타이머가 작동하지 않도록 엄격히 제한.
- **거북목-화면 거리 로직 통합**: 화면 거리 기준을 절대 수치(고정 임계값)로 처리하도록 통합하여 판정의 일관성 확보.

## 3. 핵심 지침 (UI 반영 문구)
- 엉덩이를 의자 안쪽 끝까지 밀착하기
- 허리를 등받이에 대고 곧게 펴기
- 양발은 바닥에 완전히 닿게 놓기
- 턱은 가볍게 몸쪽으로 당기기

## 4. 검증 결과
- **UI 일치성**: 팝업 및 사이드 패널이 설계대로 노출되며, DPI 배율 변화에도 레이아웃이 유지됨을 확인.
- **비정상 시작 방지**: 메인 화면에서 설정 변경 후 복귀 시 탐지 세션이 자동으로 시작되지 않음을 확인.
- **안정성 확인**: `BaselineScreen`에서 발생하던 `AttributeError` 해결 및 모든 판정 워커의 정상 작동 확인.
