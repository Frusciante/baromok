# DB 자세 추가 및 UI 효과 개선 계획

## 1. 개요
세션 통계의 정확성을 위해 '고개 숙임' 자세를 DB 집계에 추가하고, 사용자 경험(UX) 개선을 위해 불필요한 정보(측정 중 각도) 및 애니메이션(웹캠 확대 효과)을 제거한다.

## 2. 주요 변경 사항

### 2.1. 세션 통계 고도화 (`src/core/session_manager.py`)
- `posture_distribution` 계산 시 `head_down` 자세 타입을 집계 대상에 포함.
- SQL 쿼리 및 마이그레이션 로직에 `head_down` 카운트 추가.

### 2.2. 측정 화면 간소화 (`src/ui/screens/baseline_screen.py`)
- 기준 자세 설정(Baseline) 중 우측 하단에 표시되던 '현재 고개 각도' 라벨 제거.
- 실시간 업데이트 로직 삭제로 화면 집중도 향상.

### 2.3. 탐지 화면 UI 안정화 (`src/ui/screens/detection_screen.py`)
- 웹캠 프리뷰 시작 시 나타나던 '카메라 연결 중' 스피너 스택 제거.
- 첫 프레임 수신 시 발생하는 위젯 전환 효과를 없애 웹캠 화면이 즉시, 정적으로 표시되도록 수정.

## 3. 검증 계획
- [ ] 통계 화면에서 '고개 숙임' 자세가 정상적으로 집계되어 표시되는지 확인.
- [ ] 기준 자세 설정 화면에서 각도 수치가 사라졌는지 확인.
- [ ] 자세 감지 시작 시 웹캠 화면이 울렁거림 없이 즉각적으로 나타나는지 확인.
