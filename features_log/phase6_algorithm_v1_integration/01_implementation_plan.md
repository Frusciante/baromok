# Phase 6: RANSAC 캘리브레이션 수집 방식 고도화 및 UI 업데이트 계획

## 1. 개요
RANSAC 캘리브레이션 모델의 정확도를 높이기 위해 기존의 단순 앞뒤 이동 수집 방식에서 **6단계 거리 분할 수집 방식**으로 로직과 UI를 고도화한다. 수집 중 발생할 수 있는 오차를 줄이기 위해 수집 시간 동안은 사용자가 정지 상태를 유지하도록 유도한다.

## 2. 작업 체크리스트 (진행 사항 파악)

- [x] **알고리즘 레퍼런스 업데이트** (`algorithm_reference.md`)
  - [x] 6단계 거리 이동 수집(각 단계별 3초 대기, 5초 수집) 방식 명시
  - [x] 수집 중 안정적인 곡선 피팅을 위해 "정지 상태 유지" 필요성 문서화

- [x] **Baseline 수집 매니저 수정** (`baseline_manager.py`)
  - [x] 총 30초(5초 * 6단계) 수집 분량에 대응하여 최소 요구 프레임 수 상향 (60 -> 120)

- [x] **캘리브레이션 화면 UI/UX 업데이트** (`baseline_screen.py`)
  - [x] 6단계 수집 안내 가이드라인 문구 반영
  - [x] 상태 머신 기반 플로우 제어 (`WAIT` 3초 ↔ `COLLECT` 5초 교차 6회 반복)
  - [x] `WAIT` 상태 시: "새로운 거리로 이동하세요" 등 이동 유도 텍스트 노출
  - [x] `COLLECT` 상태 시: "움직이지 마세요", "가만히 유지해 주세요" 등 정지 유도 텍스트 노출
